# Проверка сборки на реальном SDK Яндекса

Порядок: залить zip черновиком → открыть черновик на десктопе и на телефоне → пройти список.
Счётчики читаются в консоли браузера: `CarsPlatform.debug` (и `CarsPlatform.debug.state`, если
сборка открыта с `?debug=1`).

## Что должен сделать пользователь в консоли разработчика

1. Создать игру, загрузить `Builds/Yandex/CarsGame-web-<version>.zip` как черновик.
2. Создать лидерборды `best_e1` … `best_e5`: тип «время», сортировка по возрастанию, миллисекунды.
3. Включить рекламу: interstitial и rewarded.
4. Заполнить карточку по `metadata.md`, объявить языки и **альбомную ориентацию**.
5. Отправить на модерацию после того, как список ниже пройден.

## Список проверки

| # | Что проверяем | Ожидаемо |
|---|---|---|
| 1 | Загрузка | `debug.log` содержит `sdk ready lang=… device=…` и `attached`; экрана «Повторить» нет |
| 2 | `ready()` | `LoadingAPI.ready()` в логе ровно один раз, в момент, когда меню готово |
| 3 | Язык | Интерфейс на языке аккаунта; переключение в настройках работает |
| 4 | Геймплей-маркеры | После заезда `debug.gameplayStarts === debug.gameplayStops` |
| 5 | Interstitial | На результатах: `debug.adOpens === debug.adCloses`, игра на паузе во время ролика, звук молчит |
| 6 | Rewarded | Кнопка «Удвоить» начисляет награду один раз; при отказе — тост, монеты не меняются |
| 7 | `game_api_pause` | Оверлей Яндекса ставит паузу и снимает её (симуляция и звук) |
| 8 | Облачный сейв | После заезда `debug.setDataCalls` ≤ 4; перезагрузка страницы сохраняет монеты и прокачку |
| 9 | Авторизация | Вход меняет игрока, прогресс мержится, гостевые данные не затирают аккаунт |
| 10 | Лидерборды | `debug.lbApi` = `v2`; рекорд появляется в таблице после финиша у авторизованного игрока |
| 11 | Призраки | `sessions.init` не отдаёт ошибку; после нескольких заездов появляются чужие призраки |
| 12 | Телефон | Тач-кнопки не перекрывают скорость и HP; текст читается; частота кадров приемлемая |
| 13 | Память | Три заезда подряд без перезагрузки: `debug.perf.heapBytes` не растёт монотонно (`null` = размер кучи прочитать не удалось, проверка не пройдена) |
| 14 | Консоль | Ошибок нет (404 `/sdk.js` допустим только на локальном сервере) |

## Известные ограничения

- Портретная ориентация не поддерживается по дизайну: в карточке объявляется альбомная.
- `multiplayer.sessions` проверялся только на моке до первого черновика.
