# CarsGame: мидкор-слой. Этапы и промпты для агента

Дата: 2026-09-10. Источник: `Docs/AI/MidcoreDesign.md` (план v2, разделы B–F). Каждый этап это один промпт для
агента (Claude Code / Codex) на 2–5 рабочих дней. Этапы идут строго по порядку: каждый следующий опирается на
код и тесты предыдущего. После каждого этапа: адверсариальное ревью диффа и запись в `ProgressLog.md`.

## Преамбула (вставлять в начало каждого промпта)

```

Перед работой прочитай: Docs/AI/UnityProjectContext.md, Docs/AI/MidcoreDesign.md (разделы B–F, план v2),

Правила:
```

## Этап 2. Система статусов и щит (P1a, ~3 дня)

```
[Преамбула]

Задача: CarStatus как общий механизм, на который сядет всё оружие. Оружия в этом этапе нет.

1. Компонент CarStatus на машине (рядом с CarController), ISimulated после CarController. Хранит фиксированный
   массив StatusEntry { int untilTick; float magnitude; } по enum StatusKind { Frozen, Slowed, Punctured, Jammed, Shielded }.
   Методы: Apply(kind, seconds, magnitude, tick), Has(kind, tick), Clear(kind), и агрегированные множители
   SpeedFactor, GripFactor, SteerWobble, WeaponsJammed. Правило агрегации: по каждому параметру берётся
   СИЛЬНЕЙШИЙ штраф из активных статусов, не произведение. Повторное наложение обновляет срок до max(старый, новый),
   не суммирует. После снятия Frozen иммунитет к Frozen 1.5 с (75 тиков).
2. Параметры по умолчанию: Frozen 1.5 с: SpeedFactor 0.5, GripFactor 0.5 и активное торможение (в CarController
   добавить ограничение горизонтальной скорости до maxSpeed*SpeedFactor через импульс, как в ApplyCoastDeceleration;
   учесть, что ApplyMotor только снимает тягу и инерцию не гасит). Slowed 2 с: SpeedFactor 0.7. Punctured 2.5 с:
   GripFactor 0.6, SteerWobble ±0.08 синусом с периодом 0.6 с. Jammed 3 с: оружие не стреляет (проверка внутри
   CarCannon.TryFire и всех будущих оружий, не только у AI). Shielded 6 с или до первого поглощённого попадания.
3. CarController читает CarStatus перед ApplyMotor/ApplySteering/ApplyFriction. AiDriver при Punctured снижает
   желаемую скорость ×0.8. AiGunner.WantsFire возвращает false при Jammed.
4. CarHealth.ApplyHit: при Shielded любой HitKind кроме Status поглощается (absorbed = true, щит снимается,
   импульс не прикладывается). Статус-эффекты в HitInfo (поле StatusKind + seconds) применяются через CarStatus,
   щит их тоже поглощает.
5. Визуал: единый владелец PropertyBlock. CarPaint получает метод SetOverlay(Color tint, float amount) и сам
   объединяет базовый цвет, wreck-тонирование (CarHealth.TintWreck) и tint статуса; никто другой Clear() на блоке
   не делает. Frozen: голубой, Punctured: без tint (искры позже), Shielded: лёгкая белая обводка через emission,
   если у материала кузова есть свойство, иначе только HUD.
6. HUD (Assets/CarsGame/Game/UI/HudScreen.cs): строка активных статусов игрока с иконкой-символом и таймером,
   обновление не чаще 5 раз/с, без аллокаций строк (заранее подготовленные тексты по ключам strings.csv).

Тесты (EditMode, чистый код CarStatus без MonoBehaviour-зависимостей, вынести логику в класс StatusSet в Core):
сроки в тиках, агрегация «сильнейший», обновление срока, иммунитет Frozen, щит поглощает ровно одно попадание.

Проверка в Play через eval: применить Frozen машине игрока на 120 км/ч, снять SpeedKmh каждые 10 тиков 3 с;
ожидаемо падение ниже 65 км/ч за ≤ 1 с и восстановление после снятия. Применить Shielded, выстрелить AI-снарядом:
HP не изменился, статус снят.

Ревью: "P1a: CarStatus with strongest-penalty aggregation, active deceleration for Frozen, shield in ApplyHit, single owner of CarPaint block".
```
