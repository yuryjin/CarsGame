# Миссия «Левиафан»: вшестером против крепости в пустыне

Дата: 2026-09-26. Статус: первая играбельная версия в коде (сессия carsgame-a1). Единый источник правды по
режиму миссий. Метки как в `ArenaMode.md`: **[решено]** — выбор пользователя; **[сделано]** — есть в коде;
**[предложение]** — не утверждено, числа черновые; **[открыто]** — ждёт решения.

## 1. Суть

**[решено]** (пользователь, 2026-09-26) Не гонка, а миссия: игрок и 5 ботов-союзников побеждают босса —
огромную медленную машину, которая идёт по пустыне. Образы: sandcrawler джав, крепость Яррика, карьерный
экскаватор Bagger 288. Босса защищают танки, броневики, летающие дроны, киборги-пехотинцы, турели и самолёты.

**[сделано]** Отдельный режим `EventMode.Mission`, событие `m1` («Левиафан»), открыто сразу, в конце списка.

| Правило | Как в коде |
|---|---|
| Победа — уничтожить ядро-реактор крепости | `BossCrawler.Core` = полоска босса в HUD |
| Поражение — крепость доползла до посёлка «Последний колодец» | конец маршрута `DesertMap`, ~1350 м, ~5 мин |
| Всегда респаун (3 с), впереди крепости, сбоку от её пути, лицом к ней | `MissionDirector.TryGetRecoveryPose` |
| Нет огня по своим (снаряды, мины, лучи) | `Teams` / `TeamTag`, фильтр в `Projectile`, `TargetFinder`, `MineHazard`, `SpecialWeaponAttack` |
| Звёзды: победа / 15 врагов / без смертей | `Event_m1.asset`, `StarGoalText` |
| Награда: победа 320 + 6 за врага (до +240); поражение — за урон по ядру | `MissionDirector.Reward` |

## 2. Карта

**[сделано]** `DesertMap` строится в рантайме в (-4000, 0, 0), трасса и её окружение прячутся (как у `AbyssTrack`).

- 1600×1600 м, играбельно ±640 м; по краю кольцо скал до ~100 м высотой — естественная граница.
- Дюны 1–2 м (едется на полной скорости), большие дюны до 11 м вдали от маршрута.
- Колея крепости — плоская укатанная полоса (цвет «такыр»).
- 16 столовых гор (укрытие), 18 ржавых остовов автобусов и цистерн вдоль маршрута, остов старого роторного
  экскаватора — ориентир размером с босса, посёлок с водонапорной башней в конце маршрута.
- Вся земля на слое `Track` (слой `Ground` дал бы травяное торможение трассы). Коллайдер один раз, ~20 тыс. треугольников.
- Небо `Sky_Desert`: тёплая дымка, туман до 900 м.

## 3. Босс «Ржавый Левиафан»

**[сделано]** `BossCrawler` + `BossPart`. 46×26 м, ~29 м высотой, 4,4 м/с по маршруту; кинематическое тело, давит.

|---|---|---|
| Ядро (корма, светящаяся решётка) | 2600 × уровень (easy 0,75, hard 1,3) | полный урон; это HP босса; +15 % урона за каждую выбитую станцию |
| Корпус | — | попадание в корпус — 50 % урона ядру |
| 4 пушечные башни | 320 | красный лазер-телеграф 1,2 с, снаряд 12, раз в 4,2 с, 105 м |
| 2 зенитки по бортам | 200 | очереди по 5–7 пуль по 2,5 |
| Миномёт | 420 | удар с красным кругом и падающим снарядом (2,6 с) |

Фазы по ядру: 66 % — ярость (+10 % скорости, десант по трапам каждые 26 с), 33 % — последний рубеж
(+25 %, десант каждые 20 с, два самолёта за налёт, всё стреляет чаще).

## 4. Охрана

**[сделано]** `MissionEnemies.cs`, эскорт — настоящие машины (`CarController`) с кузовами из гаража.

| Враг | Как устроен |
|---|---|
| Танки | кузов `grizzly`, пушка, 240 HP; выходят из кормовых ворот (фаза 2+) |
| Броневики | кузов `raider`, пулемёт, 140 HP; патрулируют вокруг крепости, гонятся за игроками |
| Дроны | квадрокоптеры, кружат над целью на 6 м, очереди после «замаха»; сбитые падают |
| Киборги-пехотинцы | роботы (без людей — `ArtDirection.md`), идут к цели, стреляют; ракетчик целится 0,9 с; **давятся машиной** |
| Турели | 3 аванпоста по 2 турели + отряд; лазер 1 с, очередь из 3 снарядов |
| Самолёты | бомбардировщики на 28 м: серия из 4 бомб или обстрел полосой; метки появляются за 2,2–2,6 с; сбил самолёт — его бомбы не падают |

Каждая смерть с неба телеграфируется (правило из `ArenaMode.md` §8).

## 5. Союзники

**[сделано]** `MissionDriver` (Side.Ally): кружат вокруг точки в 14 м за кормой (у ядра) на 36–50 м, не заезжают перед колесом,
отвлекаются на эскорт в 75 м и на пехоту/турели в 55 м (пехоту давят). Стреляют через `AiGunner`, который теперь
видит и юнитов (`TargetFinder.FindUnit`). У союзников нет мин, прочность ×1,5.
В миссии башня любой машины поворачивается на ±80° (обычно ±30°): стрельба на проезде мимо 46-метровой цели.

## 6. Технически

- Всё в тике симуляции: `MissionDirector` (порядок `int.MaxValue-6000`) двигает босса и решает исход; юниты
  (`MissionUnit`, `-5000…`) — после машин и до снарядов.
- Мягкие юниты (дроны, пехота, самолёты) на слое 2 (`Ignore Raycast`): колёса их не видят, столкновения
  Car×слой 2 выключаются на время миссии (`Physics.IgnoreLayerCollision`), снаряды попадают.
- Всё процедурное, вершинные цвета, без текстур: общий меш на тип юнита, всё удаляется при выходе.
- Хуки в общих файлах — по несколько строк: `RaceSpawner.Site`, `RaceParticipant.Site`, `RaceManager.EndMission`,
  `GameFlow` (создание/разбор), `CarCannon`/`AiGunner`/`TargetFinder`/`Projectile`/`MineHazard`/`SpecialWeaponAttack`
  (юниты и команды), `HudScreen` (захват прицела), `StarGoalText`, `MenuScreens`.
- Тест: `Tests/PlayMode/MissionPlayTests` — миссия целиком с ботом на месте игрока, статистика и скриншоты.
