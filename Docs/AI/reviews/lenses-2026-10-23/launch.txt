Сборка: WebGL (Unity 6), страница уже раздаётся локально: http://127.0.0.1:8791/index.html?sdk=mock&lang=ru
(параметр lang принимает ru/en/de/es/fr/pt/tr/uk/zh; ?sdk=mock — локальная заглушка платформы Яндекс Игр, прогресс хранится в localStorage браузера).

Правила машины (обязательно): любой браузер запускать только через `webtest -t 800 -- node <script>` (очередь, не больше двух браузеров
на машине, лимит CPU и времени); Chrome запускать через playwright-core (/home/user/gstack/node_modules/playwright-core/index.mjs)
с channel 'chrome' и аргументами из $WEBTEST_CHROME_ARGS; в конце всегда закрывать браузер. Никаких других браузеров/MCP не использовать.

Готовый драйвер: /tmp/claude-1000/-home-user-projects-games-Unity-newgames-CarsGame/4d0fdb6d-3883-49d7-ab42-027ef217c060/scratchpad/lenses-2026-10-23/tools/play.mjs
— шаги задаются в STEPS (описание в шапке файла). Пример одного заезда:
  URL='http://127.0.0.1:8791/index.html?sdk=mock&lang=ru' OUT=<моя папка> PROFILE=<моя папка>/profile \
  STEPS="shot:01-menu,state,click:0.32:0.65,wait:6,shot:03-race-start,hold:KeyW:6000,shot:04-driving,hold:KeyW+ControlLeft:5000,state,shot:05-shooting" \
  webtest -t 800 -- node .../tools/play.mjs
Координаты кликов — доли ширины/высоты канваса (в главном меню 1280×720 жёлтая кнопка «Гонка» ≈ 0.32:0.65, карточки справа ≈ 0.73:0.27 / 0.73:0.45 / 0.73:0.63); остальное смотрите по скриншоту и подбирайте. Один вызов = одна сессия браузера;
с PROFILE сейв сохраняется между вызовами (как повторный запуск игры), без PROFILE — каждый раз новый игрок.

Управление в игре (клавиатура): W/S или стрелки — газ/тормоз-назад, A/D — руль, Space — тормоз, Ctrl — огонь, Shift или E — второе оружие,
R — сброс машины, 1…0 — выбор основного оружия, колесо мыши — перебор оружия, удержание Q — колесо оружия, Esc — пауза.
Мышь наводит башню, если в настройках выключено «Автонаведение». Тач: TOUCH=1 (телефон 812×375) или cmd:touch|on.

Состояние игры без скриншота: шаг `state` печатает JSON (экран/flow, гонка, позиции, здоровье и т.п.) — предпочитайте его скриншотам.
QA-команды (шаг cmd): cmd:goto|garage (или main, events, settings…), cmd:startRace|e1|easy (события e1…e20, уровни сложности easy/normal/hard),
cmd:daily, cmd:finish (мгновенно завершить гонку), cmd:autopilot|on (ИИ ведёт машину игрока), cmd:touch|on.
Гонка идёт в реальном времени (обычно 2–4 минуты); запуск страницы занимает 10–30 с.
