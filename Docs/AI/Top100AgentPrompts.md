# Топ-100 CarsGame — задания и промпты для агентов

Номера соответствуют исходному продуктовому списку. Одна строка — один результат для игрока, шаги исполнителя и способ приёмки. Выбранная сейчас задача — №98. Для неё есть отдельная [раздача четырём агентам](TrainBossAgentPrompts.md).

## Как выдавать работу

1. Для №98 выдать блок А из файла поезда. Когда А передаст согласованные точки подключения, выдать блоки Б, В и Г. Первый совместный результат — физический обгон поезда у стрелки.
2. Для остальных карточек скопировать промпт нужного направления. В каждом уже выбран конкретный первый номер. При следующей выдаче заменить номер в первом предложении. Агент выполняет одну карточку, включая её подзадачи и проверку. Новые режимы и дорогостоящие идеи остаются кандидатами, пока для них не выбрали карточку.
3. Если у двух карточек общий файл, работу над этой частью получает один редактор. Для одновременных изменений `GameFlow`, `RaceManager` и платформенного жизненного цикла правки сводит ведущий текущей выдачи. Для `MenuScreens`, `HudScreen`, `strings.csv`, generated tables и CJK-атласа выбирают одного редактора интерфейса. Для `SaveData`, миграции и облачного слияния — одного редактора сохранений. Остальные передают конкретные значения, место вызова и ожидаемое поведение. При последовательной работе всё это может сделать исполнитель карточки.
4. Результат каждой выдачи — что теперь делает игрок, какие файлы затронуты, что измерено или проверено, на какой ревизии и где доказательство. Для исследования достаточно данных и решения, которое из них следует. Если для вывода нужен физический телефон, человек или доступ к черновику площадки, в отчёте отдельно указать полученные данные и оставшийся ручной шаг.

**Рабочая база.** Прочитать `AGENTS.md`, `README.md`, реестр рисков и последние записи журнала. Проверить `git status --short` и сохранить работу других участников. Условия запуска Unity и браузера действуют и в отдельных worktree. Каждому активному Unity нужны свои `CG_WORK`, `SIM` и `CG_QA_CONFIG_HOME`. Скрипты QA работают через `Tools/qa/common.sh`. Браузерные тесты запускать через `webtest` с `WEBTEST_CHROME_ARGS` на NVIDIA Vulkan, закрывать браузер в `finally`, звук оставлять в `AgentSink`. Исходник переводов — `strings.csv`, обновление для девяти языков — через `Tools/qa/loc-bake.sh`. Проверки выбирать по затронутому поведению. Перед сравнением разных прогонов сверять манифесты фактических входов SIM. [Правила проекта](../../AGENTS.md) · [QA](../../Tools/qa/README.md) · [Реестр рисков](UnityProjectHealth.md) · [Журнал](ImprovementCycle-2026-10-25.md)

**Порядок следующих выдач.** При переходе от поезда к основной игре я бы начал с наблюдения №3, ошибки меток №6 и хранения призраков №5. Наблюдение поможет выбрать между №1 и №12. Слоты призраков №5 пригодятся для №30 и №85. Если №41 и №7 идут в одной версии, сначала определить правило очков №41, затем подключить таблицу №7 и показ отставания №49. №99 и №100 используют один сетевой фундамент, первый живой матч достаточно реализовать в одном из этих режимов.
